sequenceDiagram
    actor Client
    participant Portfolio
    participant Orders
    participant InProgress
    participant TerminalState
    
    Client->>+Orders: Place Order
    alt can place order
        Client->>+Orders: Place Order
        Orders->>InProgress: Move to InProgress
        alt scheduled order

            alt target price met
                alt all units available
                    InProgress->>TerminalState: Transaction Sucess(allot avaiable units)
                    TerminalState-->Portfolio: Update portfolio
                    TerminalState-->Client: Update Balance

                else partial unit available
                    InProgress->>TerminalState: move to Transaction Sucess(allot avaiable units)
                    TerminalState-->InProgress: create new InProgress record with same OrderId
                    TerminalState-->Portfolio: Update portfolio
                    TerminalState-->Client: Update Balance
                    InProgress->>InProgress: wait for units
                end
            else target price not met
                InProgress->>InProgress: wait for target price
            end



        else not scheduled order

            

                alt units available
                    InProgress->>TerminalState: Transaction Sucess(allot avaiable units)
                    TerminalState-->Portfolio: Update portfolio
                    TerminalState-->Client: Update Balance

                else partial unit available
                    InProgress->>TerminalState: move to Transaction Sucess(allot avaiable units)
                    TerminalState-->InProgress: create new InProgress record with same OrderId
                    TerminalState-->Portfolio: Update portfolio
                    TerminalState-->Client: Update Balance
                    InProgress->>InProgress: wait for units
                end

        end
    
    
    else cannot place order
        Orders-->Client: Notify failure
    
    end
